# 🎟 TicketPro — сайт заказа билетов на мероприятия

Flask + MySQL. **База данных создаётся автоматически при запуске** — и сама база `ticket_db`,
и все таблицы, и демо-мероприятия (кино, театр, концерт, стендап, хоккей, фестиваль).

## Запуск

1. Установите зависимости:
   ```
   pip install flask mysql-connector-python
   ```
2. Откройте `app.py` и впишите пароль MySQL в `DB_CONFIG` (строка `"password": "ВАШ_ПАРОЛЬ"`).
3. Запустите:
   ```
   python app.py
   ```
4. Откройте в браузере: http://127.0.0.1:5000

## Структура проекта

```
ticket_web/
├── app.py              # сервер Flask + автосоздание БД (init_db)
├── templates/
│   ├── base.html       # общий каркас (шапка, меню, подвал)
│   ├── index.html      # афиша
│   ├── auth.html       # вход и регистрация
│   ├── event.html      # страница мероприятия: схема зала как в кино
│   ├── orders.html     # мои заказы (оплата, отмена, QR-коды)
│   └── admin.html      # панель администратора
└── static/
    └── style.css       # оформление
```

## Возможности

- Регистрация/вход (пароли хешируются: SHA-256 + соль)
- Афиша с карточками и эмодзи-иконками жанров
- Схема зала как в кинотеатре: экран, ряды А–Н, выбор мест кликом, до 6 билетов за заказ
- Защита от двойной покупки: транзакция + `SELECT ... FOR UPDATE`
- Оплата и отмена заказов (при отмене места возвращаются в продажу)
- QR-код каждого билета
- Админ-панель: площадки, мероприятия, типы билетов с автогенерацией мест

## Как сделать администратора

```sql
UPDATE users SET role='admin' WHERE email='ваш@email.ru';
```
